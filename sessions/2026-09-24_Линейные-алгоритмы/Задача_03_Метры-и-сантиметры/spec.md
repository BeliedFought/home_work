# Спецификация: Метры и сантиметры

Задача с автоматической проверкой. Источник: school.mos.ru, Информатика, задача №3.

Исходный скриншот условия: `input/screenshots/task_condition.jpg`. Исходное имя в загрузках Telegram: `photo_2026-09-24_22-07-53.jpg`.

---

## Условие

Дано расстояние в сантиметрах. Найти число полных метров в нем и оставшихся сантиметров.

## Вход и выход

- Вход: одно целое число - расстояние в сантиметрах
- Выход: строка вида `<метры>m <сантиметры>cm`

| № теста | Вход | Выход |
|---------|------|-------|
| 1 | 25610 | 256m 10cm |

Файл примера входа: `input/data/example_1.txt` (`25610`). Код решения: `output/code/Метры-и-сантиметры_01.py`.

## Ограничения

- Время выполнения: < 1000 ms
- Выделяемая память: 256 mb
- Язык сдачи: Python
- Максимум баллов: 1

## Ограничение по конструкциям

Деление и остаток для этой задачи разрешены (метод выбран пользователем); без подсказок ввода, пользовательских функций, импортов и f-строк.

## Код решения

`output/code/Метры-и-сантиметры_01.py`: число читается в переменную `A` без подсказки; метры - `A // 100`, сантиметры - `A % 100`; вывод по образцу.

## Варианты решения

Все варианты решения сохраняются в `output/code/` одной нумерацией `<имя>_<NN>.py`; финальный - последний номер.

| Вариант | Файл | Подход | Причина замены |
|---------|------|--------|----------------|
| 1 (финальный) | `output/code/Метры-и-сантиметры_01.py` | Деление и остаток: `A // 100`, `A % 100` | Текущий вариант |

## Критерии приемки

- Пример из условия проходит: вход `25610`, выход `256m 10cm`
- Формат вывода точно по образцу, без лишних строк
- Программа читает данные со стандартного ввода
