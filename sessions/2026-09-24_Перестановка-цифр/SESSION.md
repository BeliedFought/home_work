## Структура сессии

| Путь | Назначение |
|------|------------|
| `SESSION.md` | Маркер и паспорт сессии |
| `doc/specs/spec_new-number.md` | Спецификация задачи: условие, пример, ограничения |
| `input/screenshots/` | Скриншоты задания: условие, пример, комментарий учителя |
| `input/data/example_1.txt` | Входные данные примера: `456` |
| `output/code/new_number.py` | Код решения задачи (финальный) |
| `output/code/variants/` | Предыдущие варианты решения: `new_number_v1.py`, `new_number_v2.py` |

## Точка входа

`output/code/new_number.py`

## Результаты

Код решения: программа читает со стандартного ввода трехзначное число и печатает число с переставленными второй и третьей цифрами. Проверка: `456` -> `465`.

## Оверрайды стандарта

Сессионных оверрайдов нет. Действует проектовый оверрайд: учебная сессия с автоматической проверкой не использует логгер, локализацию и конфигурацию, вывод идет только в стандартный вывод (`doc/specs/overrides.md`).
