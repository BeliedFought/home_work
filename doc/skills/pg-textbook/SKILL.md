# Пояснение к задачам в виде учебника

Проектный навык репозитория `home_work` (префикс `pg-`, слаг `pr_glob`). Задает единое оформление пояснений к задачам, чтобы дизайн не расходился от агента к агенту.

## Когда использовать

- Создание пояснения к задачам новой сессии
- Обновление существующего пояснения
- Запросы: объяснение, разбор задач, учебник, пояснение для ребенка

## Инструкция

### 1. Два файла на сессию

В корне сессии создаются два файла с одинаковым содержанием:

- `Объяснение_<идентификатор-сессии>.txt` - обычный текст
- `Объяснение_<идентификатор-сессии>.html` - учебник по эталонному шаблону

Имя содержит идентификатор сессии: пояснения разных сессий можно собрать в одну папку без перезаписи.

### 2. Текстовая версия

Структура и образец - `templates/explanation.txt`: заголовок прописными буквами, разделы, списки через дефис, код с отступом четыре пробела. Разметка markdown не используется.

### 3. HTML-версия

Скопировать `templates/explanation.html` и заменить содержание. Дизайн - эталон, менять его нельзя. Обязательные элементы:

- обложка с названием и перечнем задач сессии
- словарь понятий карточками
- по каждой задаче: условие, идея, блок-схема «ввод - обработка - вывод», код, разбор по строчкам
- инфографика на CSS: схема цифр (классы `digit`, `swap`, `move`), уравнение (`pill`, `pill res`), полоса-разбивка (`bar`)

### 4. Правила

- Содержание текстовой и HTML-версий совпадает; HTML - оформление того же текста, не новый текст
- Внешние зависимости запрещены: стили и схемы внутри файла, без подключения из сети
- HTML по `code_standards.md` 04: `<!doctype html>` первой строкой, charset, `lang`, семантика, стили в `style`, отступ 2 пробела, осмысленные классы, без инлайновых стилей, без атрибута `type` у `style` и `script`
- Типографика репозитория: дефис вместо тире, без ё, без многоточий, без эмодзи и восклицательных знаков
- Тон - для начинающего; каждый новый термин объясняется на месте

## Критерии завершения

- Оба файла созданы в корне сессии, имена по шаблону с идентификатором сессии
- HTML использует эталонный дизайн из `templates/explanation.html`
- Содержание версий совпадает
- Типографика и требования HTML к коду соблюдены
