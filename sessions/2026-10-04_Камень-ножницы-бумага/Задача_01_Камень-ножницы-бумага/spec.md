# Спецификация: Победитель в игре «Камень, ножницы, бумага»

Теоретическое задание без автоматической проверки. Источник: задание в Telegram, предмет «Программирование».

Исходный скриншот условия: `input/screenshots/task_condition.jpg` (исходное имя в загрузках Telegram: `photo_2026-10-04_13-41-48.jpg`). В превью мессенджера текст обрезан на слове «ножни»; пользователь подтвердил, что полный текст условия совпадает с приведенным ниже.

Вторая картинка из того же чата (мем «Виды клювов и их предназначения», `photo_2026-10-04_13-27-32.jpg`) к заданию не относится и в сессию не включена.

## Условие

Напиши словесный алгоритм (логику игры) для определения победителя в игре «Камень, ножницы, бумага».

## Уточнения пользователя

- Текст условия полный, обрезанного продолжения нет
- Результат - только словесный алгоритм; код на Python не нужен (язык еще не изучался)

## Вход и выход

- Вход: выбор каждого из двух игроков - один из трех предметов (камень, ножницы, бумага)
- Выход: словесный ответ - ничья или победитель (тот, кто показал побеждающий предмет)

## Ограничения

- Автопроверки нет: задание сдается учителю в текстовом виде
- Формат решения: словесная запись по шагам, без кода
- Язык решения: русский

## Решение

`output/Камень-ножницы-бумага_01.txt` - словесный алгоритм из четырех шагов: тайный выбор предметов двумя игроками, одновременное показывание, сравнение по правилам (ничья при совпадении плюс три правила «кто кого накрывает»), объявление результата.

Симметричная запись: правила сформулированы «предмет против предмета», поэтому три правила покрывают все девять комбинаций выбора (три ничьи, по три выигрышных комбинации у каждого игрока). Развернутая альтернатива - проверка от лица игрока 1 (три проверки и «во всех остальных случаях победил игрок 2») - здесь зафиксирована, в ответ не включена.

## Критерии приемки

- Описан ввод: оба игрока тайно выбирают предмет, выбор показывается одновременно
- Ничья описана (одинаковые предметы)
- Три правила победы корректны: бумага накрывает камень, камень ломает ножницы, ножницы режут бумагу
- Правила вместе с ничьей покрывают все девять комбинаций выбора
- Результат объявляется, алгоритм завершается
- Запись словесная, по шагам, без кода
