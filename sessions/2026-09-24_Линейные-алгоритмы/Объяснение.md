# Объяснение: как решали задачи

---

## Слова, которые встретятся

- **Переменная** - это коробка с именем. В нее кладут значение, а потом достают. Например, в коробке `A` лежит то, что ввели.
- **`input()`** - команда «прочитай то, что написали с клавиатуры». Получается текст.
- **`int()`** - команда «преврати текст в целое число», чтобы можно было считать.
- **`str()`** - команда «преврати число обратно в текст», чтобы склеить его с другими кусочками.
- **`print()`** - команда «покажи на экране».
- **Склеивание через `+`** - соединяет кусочки в один. Например, `"ма" + "ма"` дает `"мама"`.
- **`A[0]`, `A[1]`, `A[2]`** - символы текста `A` по порядку. Счет начинается с нуля: `A[0]` - первый символ, `A[1]` - второй, `A[2]` - третий.
- **`//`** - деление нацело. Показывает, сколько целых раз одно число помещается в другое.
- **`%`** - остаток от деления. Показывает, что осталось лишним.

## Задача 1. Новое число

**Что просили.** Дано трехзначное число. Надо поменять местами вторую и третью цифры. Пример: из `456` должно получиться `465`.

**Как решали.** Число удобно читать как текст. Тогда каждая цифра - это отдельный символ. У числа `456` первый символ `4`, второй `5`, третий `6`. Надо поставить их в порядке: первый, третий, второй - получится `465`.

**Код:**

```python
A = input()
B = A[0] + A[2] + A[1]
print(B)
```

**Что происходит по строчкам:**

- `A = input()` - читаем число. Пока это текст, например `"456"`.
- `B = A[0] + A[2] + A[1]` - берем первый символ, потом третий, потом второй и склеиваем: `"4" + "6" + "5"` дает `"465"`. Результат кладем в коробку `B`.
- `print(B)` - показываем, что получилось.

**Главная мысль.** Мы ничего не считали, а просто переставили символы. Так короче и понятнее.

## Задача 2. Цифры числа

**Что просили.** Дано четырехзначное число. Поменять вторую и третью цифры, а потом показать сумму исходного и нового чисел в виде `2561+2651=5212`.

**Как решали.** Так же, как в первой задаче: цифры - это символы. Только их теперь четыре. Меняем второй и третий символы, получаем новое число. Потом складываем два числа.

Складывать текст нельзя: `"2561" + "2651"` даст `"25612651"`, а нам нужна сумма. Поэтому превращаем текст в числа через `int()`, складываем и превращаем ответ обратно в текст через `str()`, чтобы склеить его со знаками.

**Код:**

```python
A = input()
B = A[0] + A[2] + A[1] + A[3]
print(A + "+" + B + "=" + str(int(A) + int(B)))
```

**Что происходит по строчкам:**

- `A = input()` - читаем число `"2561"`.
- `B = A[0] + A[2] + A[1] + A[3]` - переставляем второй и третий символы: `"2" + "6" + "5" + "1"` дает `"2651"`.
- `print(...)` - собираем ответ: исходное число, знак `+`, новое число, знак `=`, сумма. Сумму считаем как `int(A) + int(B)`, затем делаем из нее текст.

## Задача 3. Метры и сантиметры

**Что просили.** Дано расстояние в сантиметрах. Найти, сколько в нем целых метров и сколько сантиметров осталось. Пример: `25610` сантиметров - это `256` метров и `10` сантиметров, ответ `256м 10см`.

**Как решали.** В одном метре сто сантиметров. Значит:

- целых метров столько, сколько раз сто помещается в числе: `25610 // 100 = 256`;
- остаток сантиметров - это то, что не поместилось: `25610 % 100 = 10`.

**Код:**

```python
A = int(input())
B = A // 100
C = A % 100
print(str(B) + "м " + str(C) + "см")
```

**Что происходит по строчкам:**

- `A = int(input())` - читаем число сантиметров и превращаем его в целое число.
- `B = A // 100` - сколько целых метров.
- `C = A % 100` - сколько сантиметров осталось.
- `print(...)` - показываем: число метров, буквы `м`, число сантиметров, буквы `см`. Числа превращаем в текст через `str()` и склеиваем с буквами.
