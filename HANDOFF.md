# HANDOFF: домашние задачи

Кратко для нового агента: что это за репозиторий, как он устроен, как решается задача и какие ошибки не повторять. Полные правила - в `AGENTS.md`, структура для человека - в `README.md`, отклонения от стандарта - в `doc/specs/overrides.md`.

---

## Что это

Репозиторий-контейнер для домашних учебных задач, в основном по программированию. Задание приходит скриншотом (обычно из школьного теста), решение сдается кодом, проверка автоматическая: программа читает данные со стандартного ввода и печатает ответ, который должен совпасть с эталоном точно.

## Как устроено

- Одна сессия - одно задание (тест, вариант): `sessions/<YYYY-MM-DD_Русский-слаг>/`
- Внутри сессии - задачи: `Задача_<NN>_<Русский-слаг>/`
- В задаче: `spec.md` (условие и ограничения), `input/screenshots/`, `input/data/`, `output/code/`
- Решения нумеруются одной серией: `<Русский-слаг>_<NN>.py`; финальное - последний номер; предыдущие варианты не удаляются
- Слаги русские, без пробелов, слова через дефис, первое слово с заглавной буквы
- Артефакты сессий коммитятся целиком (оверрайд к 06.01); исключены только секреты, окружение, кэши и `.trash/`
- К каждой сессии - пояснение к задачам в двух форматах: `Объяснение_<идентификатор-сессии>.txt` (текст) и `Объяснение_<идентификатор-сессии>.html` (учебник со схемами-инфографикой); имя привязано к сессии, файлы разных сессий не конфликтуют при сборе в одну папку. Эталон оформления - навык `textbook`, дизайн не менять

## Рабочий процесс новой задачи

1. Найти свежие скриншоты: `~/Downloads/Telegram Desktop/` (отбирать по времени изменения)
2. Прочитать все скриншоты задания, выписать условие, пример входа и выхода, ограничения, комментарий учителя
3. Определить сессию (задание) и задачу; завести папки по схеме выше
4. Записать `spec.md`; скриншоты сохранить в `input/screenshots/`, входные данные - в `input/data/`
5. Выбрать метод решения; при неясности - спросить пользователя
6. Написать решение в `output/code/<слаг>_01.py`; проверить на примере из условия
7. Каждый следующий вариант - следующим номером; причину смены записать в `spec.md`
8. Коммит (`feat(...)` или `fix(...)`)

## Правила решения

- Только пройденные в школе конструкции и операции; что разрешено - фиксировать в `spec.md` (по комментарию учителя и уточнениям пользователя)
- Ввод без подсказки: `input()` без аргумента, в стандартный вывод идет только ответ
- Задачи про символы решать символами (индексы строки, склейка), а не вычислениями, если так задано
- Деление и остаток - только если для задачи разрешены
- Комментарии и docstring на русском; идентификаторы в коде английские
- Не приписывать учителю то, чего он не говорил; домысел помечать или уточнять у пользователя

## Источники решения

Каскад `project_standards.md` 07.06: локальный контекст -> context7 (документация библиотек) -> GitHub (практики, аналоги, реальный код) -> веб-поиск (тексты ошибок). Методика - в навыке `search-sources`.

## Уроки этой сессии

- Не выдумывать. Формулировки «стиль учителя» и «умножение цифр на разряд» были домыслом агента, а не словами учителя. Источник требования проверять и указывать.
- Проверять стандарт вывода. Подсказка в `input("...")` попадает в stdout и ломает автопроверку; нужен `input()` без аргумента.
- Согласовывать структуру заранее. В этой сессии было много переделок раскладки (input и output, варианты решения, имена папок и файлов). Схему лучше утвердить один раз до массовых переносов.
- Хранить варианты с самого начала. Первые версии решения перезаписывались; восстанавливать пришлось из истории. Правило «все варианты сохраняются» появилось уже по ходу.
- Скриншоты - постоянные артефакты задачи, а не временные файлы.
- Слаги в этом репозитории русские, с заглавной буквы - это осознанный оверрайд, технические идентификаторы остаются английскими.
- Навык `glob-update-indexes` пересобирает `doc/skills/_index_skills_repo.md` и `doc/specs/_index_specs.md` каркасом и сбрасывает ручные правки (типы файлов, карту маршрутизации). После запуска их нужно доработать вручную.

## Где что лежит

- `AGENTS.md` - правила агента и точки входа
- `README.md` - описание репозитория для человека
- `doc/specs/overrides.md` - согласованные отклонения от стандарта
- `doc/skills/` - общие навыки; `data/skills/` - локальные репозитория (`search-sources`, `textbook`)
- `sessions/` - сессии с задачами; текущая - `2026-09-24_Линейные-алгоритмы` (три задачи, пояснения `Объяснение_2026-09-24_Линейные-алгоритмы.txt` и `.html` для ребенка)
