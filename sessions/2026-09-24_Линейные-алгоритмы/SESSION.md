## Структура сессии

Сессия соответствует одному заданию; внутри - задачи `Задача_<NN>_<Русский-слаг>/`. Каждая задача самодостаточна.

| Путь | Назначение |
|------|------------|
| `SESSION.md` | Маркер и паспорт сессии |
| `Объяснение.txt` | Разбор решений простым языком, обычным текстом |
| `Задача_01_Новое-число/` | Задача №1 «Новое число - 8» |
| `Задача_02_Цифры-числа/` | Задача №2 «Цифры числа - 3» |
| `Задача_03_Метры-и-сантиметры/` | Задача №3 «Метры и сантиметры» |

Структура одной задачи:

| Путь | Назначение |
|------|------------|
| `spec.md` | Спецификация задачи: условие, пример, ограничения |
| `input/screenshots/` | Скриншоты задания |
| `input/data/` | Входные данные |
| `output/code/` | Версии решения `<имя>_<NN>.py` одной нумерацией; финальный - последний номер |

## Задачи

| Задача | Название | Решение | Статус |
|--------|----------|---------|--------|
| `Задача_01_Новое-число` | Новое число - 8 | `output/code/Новое-число_05.py` | сдана, принята площадкой (сдан вариант 4) |
| `Задача_02_Цифры-числа` | Цифры числа - 3 | `output/code/Цифры-числа_03.py` | решена |
| `Задача_03_Метры-и-сантиметры` | Метры и сантиметры | `output/code/Метры-и-сантиметры_02.py` | решена |

## Результаты

Код решений по задачам задания; материалы задач сохранены в `input/`, версии решения - в `output/code/`.

## Оверрайды стандарта

Сессионных оверрайдов нет. Действуют проектовые оверрайды: упрощенный вывод без логгера, локализации и конфигурации; раскладка материалов по подпапкам задачи (`doc/specs/overrides.md`).
