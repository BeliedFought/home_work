# home_work

Соответствует стандарту: 4.14.3

## Назначение

Репозиторий для решения домашних учебных задач, в основном по программированию. Одна задача - одна сессия в папке `sessions/`. Основной язык задач - Python, встречаются SQL и базы данных.

Репозиторий-контейнер: сам он ничего не запускает, код и окружение живут внутри сессий. Пакет `doc/standards/` - копия стандарта и только читается.

## Как решается задача

1. Задание приходит скриншотами из Telegram. Свежие файлы лежат в `~/Downloads/Telegram Desktop/` (`photo_<дата>_<время>.jpg`).
2. Заводится сессия `sessions/<YYYY-MM-DD_Суть-задания>/` с файлом `SESSION.md` - маркером и паспортом. Одна сессия соответствует одному заданию (тесту) и может содержать несколько задач.
3. Каждая задача раскладывается в папку `Задача_<NN>_<Русский-слаг>/`: `spec.md` (условие), `input/screenshots/` (скриншоты), `input/data/` (данные), `output/code/` (код решения).
4. Версии решения размещаются в `output/code/` задачи одной нумерацией `<Русский-слаг>_<NN>.py`; финальная - последний номер; проверяется на примере из условия.

Задачи с автоматической проверкой читают данные со стандартного ввода и печатают ответ в стандартный вывод. Формат вывода совпадает с ожидаемым точно; отладочные строки недопустимы.

## Структура файлов и директорий

| Путь | Назначение |
|------|------------|
| `AGENTS.md` | Инструкции для AI-агента: точки входа, правила работы, поиск задания, структура |
| `HANDOFF.md` | Общий разбор работы и уроки для новых агентов |
| `README.md` | Документация репозитория для человека |
| `.gitignore` | Исключения git: секреты, кэши, локальные данные, `tmp/`, `.trash/` |
| `.gitattributes` | Окончания строк: текстовые файлы хранятся с LF |
| `doc/standards/` | Пакет стандартов проекта; копия хаба, только для чтения |
| `doc/skills/` | Общие навыки агента `glob-*`; реестр - `_index_skills_repo.md` |
| `data/skills/` | Локальные навыки репозитория без префикса; индекс - `_index_skills_pl.md` |
| `doc/specs/` | Спецификации репозитория: оверрайды, индекс, шаблоны |
| `doc/specs/overrides.md` | Реестр согласованных отклонений репозитория от стандарта |
| `doc/specs/_index_specs.md` | Индекс каталога спецификаций |
| `doc/specs/spec_ui.html` | Универсальный шаблон UI-эталона (создается в сессии при необходимости) |
| `doc/specs/text_overrides.md` | Шаблон текстового оверрайда (доменные термины) |
| `doc/change_requests/` | Задания на изменение (CR) и их индекс |
| `doc/agent_questions/` | Уточняющие вопросы агента (транзитная папка) |
| `sessions/` | Сессии: одна сессия на задание (тест), внутри - задачи |
| `sessions/<session>/SESSION.md` | Маркер и паспорт сессии, список задач |
| `sessions/<session>/Объяснение_<session>.txt` | Пояснение к задачам обычным текстом (коммитится) |
| `sessions/<session>/Объяснение_<session>.html` | То же в виде учебника со схемами-инфографикой (коммитится) |
| `sessions/<session>/Задача_<NN>_<Русский-слаг>/` | Задача внутри сессии; слаги русские, без пробелов |
| `sessions/<session>/Задача_<NN>_<Русский-слаг>/spec.md` | Спецификация задачи (коммитится) |
| `sessions/<session>/Задача_<NN>_<Русский-слаг>/input/screenshots/` | Скриншоты задания (коммитится) |
| `sessions/<session>/Задача_<NN>_<Русский-слаг>/input/data/` | Входные данные (коммитится) |
| `sessions/<session>/Задача_<NN>_<Русский-слаг>/output/code/` | Версии решения `<Русский-слаг>_<NN>.py`, финальный - последний номер (коммитится) |
| `.trash/` | Карантин удаляемых файлов (локальная папка, не коммитится) |

## Навыки

Общие (реестр - `doc/skills/_index_skills_repo.md`):

- `glob-update-indexes` - актуализация локальных индексов
- `glob-skill-deploy` - деплой навыков в инструменты
- `glob-audit-repository` - аудит репозитория на соответствие стандарту
- `glob-cfg-pip` - настройка зеркала PyPI
- `glob-skill-migrate-anthropic` - миграция навыков в формат SKILL.md
- `glob-update-kilo-rules` - проверка конфигурации Kilo

Локальные репозитория (реестр - `data/skills/_index_skills_pl.md`):

- `search-sources` - порядок поиска источников решения учебных задач
- `textbook` - пояснение к задачам в виде учебника
