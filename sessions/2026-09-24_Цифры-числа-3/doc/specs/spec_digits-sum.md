# Спецификация: Цифры числа - 3

Задача с автоматической проверкой. Источник: school.mos.ru, Информатика, задача №2.

Исходные скриншоты условия - входящие материалы задания: `input/screenshots/task_condition.jpg`, `input/screenshots/task_example.jpg`. Исходные имена в загрузках Telegram: `photo_2026-09-24_21-51-12.jpg`, `photo_2026-09-24_21-51-15.jpg`.

---

## Условие

Дано четырехзначное число. Напишите программу, которая получает новое число, образуемое перестановкой второй и третьей цифр заданного числа. Выведите на экран сумму исходного и нового чисел по образцу выходных данных из примера.

## Вход и выход

- Вход: одно четырехзначное целое число
- Выход: строка вида `<исходное>+<новое>=<сумма>`

| № теста | Вход | Выход |
|---------|------|-------|
| 1 | 2561 | 2561+2651=5212 |

Файл примера входа: `input/data/example_1.txt` (`2561`). Код решения: `output/code/new_number_sum.py`.

## Ограничения

- Время выполнения: < 1000 ms
- Выделяемая память: 256 mb
- Язык сдачи: Python
- Максимум баллов: 1

## Ограничение по конструкциям

Использовать пройденные конструкции: `input`, `print`, `int`, `float`, `str`; без пользовательских функций, импортов и f-строк. Число обрабатывается как строка, деление и остаток (`//`, `%`) не применяются.

## Код решения

`output/code/new_number_sum.py`: число читается как строка; вторая и третья цифры меняются местами конкатенацией; сумма считается через `int()` и выводится по образцу.

## Варианты решения

Все варианты, созданные в сессии, сохраняются: финальный - в `output/code/`, предыдущие - в `output/code/variants/`.

| Вариант | Файл | Подход | Причина замены |
|---------|------|--------|----------------|
| 1 | `output/code/variants/new_number_sum_01.py` | Линейный код, `int`, деление и остаток | Деление и остаток не пройдены |
| 2 (финальный) | `output/code/new_number_sum.py` | Строка: индексация и конкатенация, `int` для суммы | Текущий вариант |

## Критерии приемки

- Пример из условия проходит: вход `2561`, выход `2561+2651=5212`
- Формат вывода точно по образцу, без лишних строк
- Программа читает данные со стандартного ввода
- Использованы только пройденные конструкции
