Задача с автоматической проверкой. Источник: school.mos.ru, Информатика, тема «Линейные алгоритмы. Работа с целыми числами», задача №1.

Исходные имена в загрузках Telegram: `photo_2026-09-24_21-34-27.jpg`, `photo_2026-09-24_21-34-30.jpg`, `photo_2026-09-24_21-34-33.jpg`.

## Условие

Дано трехзначное число. Написать программу, которая получает новое число, образованное при перестановке второй и третьей цифр заданного числа.

## Вход и выход

- Вход: одно трехзначное целое число
- Выход: одно целое число

| № теста | Вход | Выход |
|---------|------|-------|
| 1 | 456 | 465 |

Файл примера входа: `input/data/example_1.txt` (`456`). Код решения: `output/code/new_number.py`.

## Ограничения

- Время выполнения: < 1000 ms
- Выделяемая память: 64 mb
- Язык сдачи: Python
- Максимум баллов: 1

## Комментарий учителя

Повторить `input`, `print`, `int`, `float`, `str`.

## Ограничение по конструкциям

Комментарий учителя задает пройденный материал: `input`, `print`, `int`, `float`, `str`.

Дополнительные требования из чата (уточнения пользователя, не из скриншота): без деления и остатка, ввод без подсказки, задача решается через символы, а не через вычисления.

Итог: `int`, умножение, деление и остаток, пользовательские функции, импорты, f-строки и подсказки ввода не применяются.

## Код решения

`output/code/new_number.py`: число читается в переменную `A` без подсказки (`A = input()`); вторая и третья цифры меняются местами как символы: `A[0] + A[2] + A[1]`. В стандартный вывод идет только ответ.

## Варианты решения

Все варианты, созданные в сессии, сохраняются: финальный - в `output/code/`, предыдущие - в `output/code/variants/`.

| Вариант | Файл | Подход | Причина замены |
|---------|------|--------|----------------|
| 1 | `output/code/variants/new_number_01.py` | Пользовательская функция, `int`, деление и остаток | Пользовательские функции не пройдены |
| 2 | `output/code/variants/new_number_02.py` | Линейный код, `int`, деление и остаток | Деление и остаток не пройдены |
| 3 | `output/code/variants/new_number_03.py` | Строка: индексация и конкатенация | Заменен на вариант с переменными и умножением |
| 4 | `output/code/variants/new_number_04.py` | Переменные, умножение цифр на разряд | Требование решать через символы, а не через вычисления |
| 5 (финальный) | `output/code/new_number.py` | Символы: `A[0] + A[2] + A[1]` | Текущий вариант |

Ограничения по конструкциям: часть задана комментарием учителя (скриншот), часть - уточнениями пользователя в чате. Умножение цифр на разряд в варианте 4 - интерпретация агента, в формулировке учителя этой детали нет.

## Критерии приемки

- Пример из условия проходит: вход `456`, выход `465`
- Вывод содержит только ответ, без служебных строк
- Программа читает данные со стандартного ввода
- Использованы только пройденные конструкции (`input`, `print`, `int`, `float`, `str`)
