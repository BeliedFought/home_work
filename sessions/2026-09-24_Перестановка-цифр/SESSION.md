## Структура сессии

| Путь | Назначение |
|------|------------|
| `SESSION.md` | Маркер и паспорт сессии |
| `doc/specs/spec_new-number.md` | Спецификация задачи: условие, пример, ограничения |
| `run/new_number.py` | Решение: чтение числа и вывод с переставленными цифрами |
| `input/task_condition.jpg` | Скриншот условия задания |
| `input/task_example.jpg` | Скриншот примера входа и выхода |
| `input/task_teacher_comment.jpg` | Скриншот комментария учителя |
| `input/example_1.txt` | Входные данные примера: `456` |
| `output/example_1.txt` | Вывод программы на пример: `465` |

## Точка входа

`run/new_number.py`

## Результаты

Программа читает со стандартного ввода трехзначное число и печатает число с переставленными второй и третьей цифрами. Проверка: `456` -> `465`.

## Оверрайды стандарта

Сессионных оверрайдов нет. Действует проектовый оверрайд: учебная сессия с автоматической проверкой не использует логгер, локализацию и конфигурацию, вывод идет только в стандартный вывод (`doc/specs/overrides.md`).
