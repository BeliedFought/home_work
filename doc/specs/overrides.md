# Проектные оверрайды стандарта

Реестр согласованных отклонений репозитория от глобального пакета стандартов. Канон - `project_standards.md`, раздел 01.01.02. Без записи в этой таблице отклонение не действует: применяется глобальное правило.

| Раздел стандарта | Отклонение | Обоснование | Дата согласования |
|------------------|------------|-------------|-------------------|
| 07.03 (пункты 7-10) | Корень репозитория не runnable: не создаются `config/config.ini`, `src/`, `.env`, `requirements.txt`, `.python-version`, `.venv` и инфраструктурные модули `src/` | Репозиторий - контейнер сессий; запускаемых точек входа на уровне корня нет, каждая задача самодостаточна и создает каркас по потребности | 2026-09-24 |
| 01.02, 01.03, 04.01, 04.06 | В учебной сессии по задаче с автоматической проверкой допускается упрощенный вывод без логгера, локализации и конфигурации: программа печатает в стандартный вывод только ожидаемый проверяющим ответ | Автоматический проверяющий сравнивает стандартный вывод с эталоном; лог и служебные сообщения искажают результат | 2026-09-24 |
| 06.01 | Артефакты сессий коммитятся полностью: скриншоты задания, входящие данные `input/`, результаты `output/`, рабочие данные `data/`. Из git исключаются только служебные каталоги (`.venv/`, `__pycache__/`, кэши) и карантин `.trash/` | Требование пользователя: все собранные артефакты задач хранятся в истории git, а не остаются локальными | 2026-09-24 |
| 01.01 | Сессия - одно задание (тест) с несколькими задачами `Задача_<NN>_<Русский-слаг>/`; материалы и результат раскладываются по подпапкам задачи: `spec.md`, `input/screenshots/`, `input/data/`, `output/code/` (а не `run/`); отдельная сессия на задачу не создается | Задание содержит несколько задач; результат задачи - код; раскладка по подпапкам задачи | 2026-09-24 |
| 01.01.01, 02.01 (`code_standards.md`) | Слаги (идентификатор сессии, имя папки задачи, имя файла решения) пишутся на русском языке, без пробелов, слова через дефис, первое слово с заглавной буквы: `2026-09-24_Линейные-алгоритмы`, `Задача_01_Новое-число`, `Новое-число_05.py` | Требование пользователя: человекочитаемые русские слаги в этом репозитории; идентификаторы внутри кода остаются английскими | 2026-09-24 |
