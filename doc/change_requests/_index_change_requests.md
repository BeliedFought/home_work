# Индекс заданий на изменение (CR)

Индекс каталога `doc/change_requests/`. Точка входа: реестр активных заданий и карта маршрутизации. Архивные задания (`.arch/`) в индексе не отражаются; их слаги учитываются при проверке уникальности новых. Скелет, реестр и карта маршрутизации - канон `index_nav_standards.md` (разделы 03, 04, 05.01, 06). Канон самих заданий - `doc/standards/change_request_standards.md`. Индекс ведется агентом вручную при любом изменении состава каталога; навык `glob-update-indexes` его не перегенерирует.

Порядок принятия решений при отсутствии или неоднозначности нормы - `project_standards.md`, раздел 07.06.

---

## Обязательность применения

Тегание этого файла (`@doc/change_requests/_index_change_requests.md`) означает обязательное использование индекса при работе с заданиями на изменение. Агент:

1. Определяет релевантные файлы по реестру и карте маршрутизации
2. Открывает только релевантные файлы, а не каталог целиком
3. При любом изменении состава `doc/change_requests/` обновляет этот индекс

Индекс применяется при любой работе с заданиями на изменение независимо от явного тегирования.

## Автоактуализация

При любом изменении состава `doc/change_requests/` (создание, смена статуса, перенос в спеку, архивация, отклонение):

1. Обновить реестр: состав, темы, статусы, исполнение
2. Актуализировать карту маршрутизации по канону `index_nav_standards.md` (раздел 04)
3. Вывести отчет: что добавлено, изменено, перенесено, отклонено
