# home_work

Соответствует стандарту: 4.14.3

## Назначение

Репозиторий для решения домашних учебных задач, в основном по программированию. Одна задача - одна сессия в папке `sessions/`. Основной язык задач - Python, встречаются SQL и базы данных.

Репозиторий-контейнер: сам он ничего не запускает, код и окружение живут внутри сессий. Пакет `doc/standards/` - копия стандарта и только читается.

## Как решается задача

1. Задание приходит скриншотом из Telegram. Свежие файлы лежат в `~/Downloads/Telegram Desktop/` (`photo_<дата>_<время>.jpg`); условие переносится в спецификацию сессии, скриншоты и данные задания сохраняются в `input/` сессии.
2. Заводится папка `sessions/<YYYY-MM-DD_Суть-задачи>/` с файлом `SESSION.md` - маркером и паспортом сессии.
3. Каркас сессии создается по потребности задачи: для задачи на Python обычно `run/` (запускаемый скрипт), `src/` (модули), `data/`, `doc/specs/`, `requirements.txt`.
4. Решение размещается в `run/` или `src/`, проверяется на примере из условия.

Задачи с автоматической проверкой читают данные со стандартного ввода и печатают ответ в стандартный вывод. Формат вывода совпадает с ожидаемым точно; отладочные строки недопустимы.

## Структура файлов и директорий

| Путь | Назначение |
|------|------------|
| `AGENTS.md` | Инструкции для AI-агента: точки входа, правила работы, поиск задания, структура |
| `README.md` | Документация репозитория для человека |
| `.gitignore` | Исключения git: секреты, кэши, локальные данные, `tmp/`, `.trash/` |
| `.gitattributes` | Окончания строк: текстовые файлы хранятся с LF |
| `doc/standards/` | Пакет стандартов проекта; копия хаба, только для чтения |
| `doc/skills/` | Навыки агента: общие `glob-*` и проектные `pg-*`; реестр - `_index_skills_repo.md` |
| `doc/specs/` | Спецификации репозитория: оверрайды, индекс, шаблоны |
| `doc/specs/overrides.md` | Реестр согласованных отклонений репозитория от стандарта |
| `doc/specs/_index_specs.md` | Индекс каталога спецификаций |
| `doc/specs/ui_spec.html` | Универсальный шаблон UI-эталона (создается в сессии при необходимости) |
| `doc/specs/text_overrides.md` | Шаблон текстового оверрайда (доменные термины) |
| `doc/change_requests/` | Задания на изменение (CR) и их индекс |
| `doc/agent_questions/` | Уточняющие вопросы агента (транзитная папка) |
| `sessions/` | Сессии: по одной папке на задачу, каждая с `SESSION.md` |
| `sessions/<session>/input/` | Входящие материалы задачи: скриншоты условия и файлы данных (коммитится) |
| `sessions/<session>/output/` | Результаты задачи (коммитится) |
| `.trash/` | Карантин удаляемых файлов (локальная папка, не коммитится) |

## Навыки

- `glob-update-indexes` - актуализация локальных индексов
- `glob-skill-deploy` - деплой навыков в инструменты
- `glob-audit-repository` - аудит репозитория на соответствие стандарту
- `glob-cfg-pip` - настройка зеркала PyPI
- `glob-skill-migrate-anthropic` - миграция навыков в формат SKILL.md
- `glob-update-kilo-rules` - проверка конфигурации Kilo
- `pg-search-sources` - порядок поиска источников решения учебных задач

Полный реестр - `doc/skills/_index_skills_repo.md`.
