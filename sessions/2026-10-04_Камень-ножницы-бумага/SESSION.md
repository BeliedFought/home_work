## Структура сессии

Сессия соответствует одному заданию; внутри - задачи `Задача_<NN>_<Русский-слаг>/`. Каждая задача самодостаточна.

| Путь | Назначение |
|------|------------|
| `SESSION.md` | Маркер и паспорт сессии |
| `Объяснение_2026-10-04_Камень-ножницы-бумага.txt` | Разбор решения простым языком, обычным текстом |
| `Объяснение_2026-10-04_Камень-ножницы-бумага.html` | То же в виде учебника со схемами-инфографикой |
| `Задача_01_Камень-ножницы-бумага/` | Задача №1 «Победитель в игре "Камень, ножницы, бумага"» |

Структура одной задачи:

| Путь | Назначение |
|------|------------|
| `spec.md` | Спецификация задачи: условие, уточнения, критерии приемки |
| `input/screenshots/` | Скриншоты задания |
| `output/` | Версии решения `<имя>_<NN>.txt` одной нумерацией; финальный - последний номер |

`output/code/` в этой сессии не создается: решение - словесный алгоритм, кода нет (Python не изучался, уточнение пользователя в `spec.md`).

## Результаты

Словесный алгоритм из четырех шагов: тайный выбор игроков, одновременное показывание, сравнение по ничьей и трем правилам, объявление результата. Материалы задачи сохранены в `input/`, версия решения - в `output/`.

## Оверрайды стандарта

Сессионных оверрайдов нет. Действуют проектовые оверрайды: упрощенный каркас без логгера, локализации и конфигурации; русские слаги; решение задачи без кода раскладывается в `output/` задачи.
