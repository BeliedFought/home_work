## Условие

Дано четырехзначное число. Напишите программу, которая получает новое число, образуемое перестановкой второй и третьей цифр заданного числа. Выведите на экран сумму исходного и нового чисел по образцу выходных данных из примера.

## Вход и выход

- Вход: одно четырехзначное целое число
- Выход: строка вида `<исходное>+<новое>=<сумма>`

| № теста | Вход | Выход |
|---------|------|-------|
| 1 | 2561 | 2561+2651=5212 |

Файл примера входа: `input/data/example_1.txt` (`2561`). Код решения: `output/code/Цифры-числа_03.py`.

## Ограничения

- Время выполнения: < 1000 ms
- Выделяемая память: 256 mb
- Язык сдачи: Python
- Максимум баллов: 1

## Ограничение по конструкциям

Использовать пройденные конструкции: `input`, `print`, `int`, `float`, `str`; без пользовательских функций, импортов и f-строк. Число обрабатывается как строка, деление и остаток (`//`, `%`) не применяются. Ввод без подсказки; для суммы используется `int`.

## Код решения

`output/code/Цифры-числа_03.py`: число читается в переменную `A` без подсказки; новое число собирается из символов в `B`; сумма считается через `int()` и выводится по образцу. Методика - как в последнем варианте задачи №1.

## Варианты решения

Все варианты решения сохраняются в `output/code/` одной нумерацией `<имя>_<NN>.py`; финальный - последний номер.

| Вариант | Файл | Подход | Причина замены |
|---------|------|--------|----------------|
| 1 | `output/code/Цифры-числа_01.py` | Линейный код, `int`, деление и остаток | Деление и остаток не пройдены |
| 2 | `output/code/Цифры-числа_02.py` | Строка: индексация и конкатенация, `int` для суммы | Приведено к методике задачи №1 |
| 3 (финальный) | `output/code/Цифры-числа_03.py` | Символы, переменные `A` и `B`, `int` для суммы | Текущий вариант |

## Критерии приемки

- Пример из условия проходит: вход `2561`, выход `2561+2651=5212`
- Формат вывода точно по образцу, без лишних строк
- Программа читает данные со стандартного ввода
- Использованы только пройденные конструкции
