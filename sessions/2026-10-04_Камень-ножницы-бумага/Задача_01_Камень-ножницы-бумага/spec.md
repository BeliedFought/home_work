# Спецификация: Победитель в игре «Камень, ножницы, бумага»

Теоретическое задание без автоматической проверки. Источник: задание в Telegram, предмет «Программирование».

Исходный скриншот условия: `input/screenshots/task_condition.jpg` (исходное имя в загрузках Telegram: `photo_2026-10-04_13-41-48.jpg`). В превью мессенджера текст обрезан на слове «ножни»; пользователь подтвердил, что полный текст условия совпадает с приведенным ниже.

Вторая картинка из того же чата (мем «Виды клювов и их предназначения», `photo_2026-10-04_13-27-32.jpg`) к заданию не относится и в сессию не включена.

## Условие

Напиши словесный алгоритм (логику игры) для определения победителя в игре «Камень, ножницы, бумага».

## Уточнения пользователя

- Текст условия полный, обрезанного продолжения нет
- Результат - только словесный алгоритм; код на Python не нужен (язык еще не изучался)
- Текст ответа упростить, школьным языком
- Задание по программированию - закрепление конструкции ветвления: сделать упор на «если - то»; затем уточнено - форма «если - иначе» (if - else)
- Пользователь попросил дополнительно готовый код на Python; словесный алгоритм - основной ответ для сдачи, код - приложение

## Вход и выход

- Вход: выбор каждого из двух игроков - один из трех предметов (камень, ножницы, бумага)
- Выход: словесный ответ - ничья или победитель (тот, кто показал побеждающий предмет)

## Ограничения

- Автопроверки нет: задание сдается учителю в текстовом виде
- Формат решения: словесная запись по шагам, без кода
- Язык решения: русский

## Решение

`output/Камень-ножницы-бумага_03.txt` - словесный алгоритм из пяти шагов: ввод (тайный выбор двух игроков и одновременный показ), ветвление цепочкой «если - то - иначе» (ничья, бумага против камня, камень против ножниц, финальное «иначе» - ножницы против бумаги), объявление результата.

Последнее правило не имеет своего «если»: финальное «иначе» выполняется, только когда ничья и две первые проверки не подошли, - остается единственный вариант «ножницы против бумаги». Цепочка построена как заготовка условного оператора: каждая ветка имеет условие и действие.

## Код решения

`output/code/Камень-ножницы-бумага_01.py` - словесный алгоритм, переведенный в код один в один: цепочка `if` / `elif` / `else`. Отличия от словесной записи:

- проверки идут от лица игрока 1: три ветки `elif` покрывают его выигрышные пары, финальное `else` - «победил игрок 2» (все пары, где выигрывает предмет игрока 2);
- `.lower()` приводит ввод к нижнему регистру, чтобы «Камень» и «камень» считались одинаковыми;
- ввод с подсказками: автопроверки у задачи нет, подсказки делают игру пригодной для запуска двумя игроками (требование «ввод без подсказки» действует только для задач с автопроверкой).

Проверено на всех девяти комбинациях ввода и на регистре («Камень», «НОЖНИЦЫ»): во всех случаях верный ответ.

## Критерии приемки

- Описан ввод: оба игрока тайно выбирают предмет, выбор показывается одновременно
- Проверки построены цепочкой «если - то - иначе»
- Ничья описана (одинаковые предметы)
- Правила победы корректны: бумага накрывает камень, камень ломает ножницы, ножницы режут бумагу
- Последний случай (ножницы против бумаги) покрыт финальным «иначе» без отдельной проверки
- Правила вместе с ничьей покрывают все девять комбинаций выбора
- Результат объявляется, алгоритм завершается
- Запись словесная, школьным языком, без кода
